Clairvoyant oracle: exact relative regret across Kalshi markets

Every Kalshi event market recorded in the window, all of them on one lattice. Each second gets one dollar node shared by every market, plus YES and NO holding nodes per market. Arcs are the recorded books (taker fees included), the prints a resting maker order could have filled against, holds, and settlement at the known result. The value of a node is what perfect hindsight earns from it. The relative regret ρ = 1 − Q(a)/V of an action is the share of that value it forfeits. Everything runs here in the page: the exact backward pass in JavaScript, and the capacitated version through generalized-maxflow compiled to WebAssembly, using its new array interface.
